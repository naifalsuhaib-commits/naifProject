# Hospital Maintenance Requests System

A specialized web-based maintenance management application tailored for hospital environments to streamline, track, and resolve equipment and facility service requests efficiently.

## 🏥 Project Overview
This system is designed to handle internal maintenance tickets within a hospital infrastructure. It ensures rapid response times by capturing critical details for every reported issue, minimizing downtime for essential medical and facility equipment.

## 📝 Key Features & Data Fields
The system captures and processes precise ticket details, including:
* **Zone/Location:** Pinpoints the exact area or building zone within the hospital.
* **Staff Member:** Records the name of the person reporting the issue.
* **Department:** Identifies the specific medical or administrative department (e.g., Radiology, ER, Lab).
* **Equipment/Device Name:** Specifies the exact asset or device requiring attention.
* **Fault Type:** Categorizes the nature of the malfunction for targeted maintenance.
* **Automated Notifications:** Triggers instant SMTP email alerts to keep technical teams and stakeholders updated.

## 🛠️ Tech Stack
* **Language/Framework:** C#, ASP.NET Web Forms
* **Database Management:** Microsoft SQL Server (Relational Database & Custom Operations)
* **Environment:** Visual Studio, IIS / SmarterASP.NET Hosting
